# 夜航练习室

## 本地启动

```sh
npm ci
npm run dev
```

在浏览器打开 Vite 输出的本机地址。麦克风需要本机地址或 HTTPS。

## Docker 启动

```sh
docker compose up --build
```

打开 <http://localhost:8029>。可以通过 `NIGHT_SESSION_PORT` 指定其他端口。

## 编辑分句与改词

- 选中一句后可在「编辑这一句」里按字数拆分。拆出的后半句标「半」，可与另一处**等长**片段交换；交换只改文字归属，乐句、循环和音高图仍停在原来的歌时位置。
- 「改词」原位替换文字。歌、词与录音都保存在本机，刷新后仍然有效。
- 撤销可逐步退回拆分、交换与改词；「还原分句」回到歌曲最初的分句。

## 练习回顾里的两种历史

- **原词**：这条录音确实唱过这一格的文字。拆分前录的整句仍属于拆出的两半；换了位置的文字，它的录音会跟着到新位置。
- **歌时**：这条录音只是与这一格的歌时相交。只唱到原句前半的录音不会跑到挪走的后半句；横跨分界的录音则能从两处找到，并在时间旁标明确切唱过的片段。
- 两种都符合时只出现一条，并同时保留「原词·歌时」两个标记。
